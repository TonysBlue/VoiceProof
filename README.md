# VoiceProof 声检

桌面优先的本机浏览器口播质检工具。选择音视频、贴入原稿，即可自动生成带时间点的转写、回听疑似错读/漏读/多读、数字/术语差异与基础音质线索，逐项确认后导出中文复核报告。正式产品决策及体验合同见 [DECISION-8](docs/product/DECISION-8.md)。本版仅供内部体验，未发布、未收费、未使用客户数据；不代表消费级安装和识别质量已获独立验收。

## 内部维护人员准备环境

Python 3.11 或 3.12，建议至少4核CPU、4GB可用内存，模型约500MB，安装依赖和首次下载模型需要网络，检查素材时完全本地运行。

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-local.lock
.venv/bin/python -m pip install -e '.[local]' --no-deps
.venv/bin/python -m voiceproof.server
```

会自动打开随机端口的 `127.0.0.1` 浏览器页面。已配置 Python 文件关联的机器可双击 `launch.pyw`；当前不提供独立安装包，内部维护人员需先准备环境。Windows 将命令中的 `.venv/bin/python` 替换为 `.venv\Scripts\python.exe`。`voiceproof-web` 是安装后的启动入口。

## 普通用户操作

1. 页面显示引擎未安装时，点击“安装本地语音引擎”。只下载模型，不发送素材。失败可重试；国内网络可达性尚未实测保证。
2. 选择 WAV、MP3、M4A、MP4、MOV、WebM、FLAC 或 OGG（1秒至10分钟、100MB以内）；粘贴原稿或导入 UTF-8 文本。可按行填写术语。
3. 点击“开始发布前检查”，等待解码、转写和对齐。点击问题时间点回听，核对原稿与识别结果。回听从问题前0.5秒开始。
4. 确认有问题后标为“必须重录”，误报可忽略。存在未复核项时结论为“建议复核”；全部忽略或无问题时仍应完整回听。导出文本保留本次复核状态；页面刷新会重置尚未导出的确认状态。
5. 点击“清空 / 取消并删除本次资料”。空转写、坏文件、超限或引擎异常会显示中文下一步，不需要提供转写、命令行或 JSON。

素材、转写与原稿仅在本机临时目录处理，不写入项目库或数据库，不含分析遥测。仅监听回环地址，拒绝异源修改请求；不能作为公网服务运行。清空、正常退出或闲置30分钟删除本次临时目录，任务15分钟超时。强制杀进程/断电可能留下操作系统临时文件，内部维护人员需清理；共享电脑与磁盘备份不在本工具隔离能力内。模型缓存保留以便下次离线检查。`VOICEPROOF_MODEL_DIR` 可由维护人员指定预先下载的 faster-whisper small 模型目录。

## 能力限制

适用于单人普通话口播。模型置信线索不是错误概率，所有差异默认建议复核，不自动要求重录。词区间为估计，中文拆字插值，漏读定位到相邻词。中文规范基数（如“一百二十/120”、年份数字串）做保守归一化；繁简字形做本地归一化，原始转写保留；同音字、方言、日期语义、口语数字与复杂术语仍可能误判或漏检。长停顿、全片音量峰值削波及低音量只是复核线索，不检测所有噪声、声道问题或听感。没有发现问题不等于发布保证。

## 验证

```bash
python3.11 -m unittest discover -s tests -v
```

需先安装 `.[local]`，媒体集成测试使用真实解码依赖。`tests/fixtures/scenarios.json` 是合成场景合同，并非客户或用户实验。真实引擎与浏览器验证方式及实测结果见 `evidence/task-8/VERIFICATION.md`。

保留原有 CLI `python -m voiceproof check-text` / `check-wav` 供开发检查；消费者页面直接使用同一对齐与音质内核。
